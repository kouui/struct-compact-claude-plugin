# struct-compact-claude-plugin

Claude Code mod (plugin name `struct-compact`). On `auto` and `manual` compaction it slims the transcript (text verbatim; tool calls reduced to a name and the file paths they read/wrote/deleted, some tools ignored; results to one-line notes), has `claude -p --model haiku` write a structured handoff (original tasks, active user instructions, related files, progress, cautions, key decisions), and returns that plus the last 4 text messages (user and assistant; tool calls and results excluded). Any failure falls back to the engine's default compaction.

## Install

```bash
claude plugin marketplace add kouui/magic-claude-code-plugin
claude plugin install struct-compact@magic-claude-code-plugin -s user
```

Or try it from a checkout without installing: `claude --plugin-dir <this folder>`.

## Requirements

- The `claude` CLI on `PATH` (the mod runs `claude -p`, which uses your Claude Code login and counts against your usage).
- A slimmed transcript is sent to the `haiku` model for summarization:
  - user and assistant text: verbatim
  - Bash / PowerShell: `description`, the first 50 chars of the command, its length, and the file paths it touches
  - Read / Edit / Write / MultiEdit / NotebookEdit: the file path only, no content
  - Agent / Task: `description` and `model` only
  - Grep / Glob: the pattern (first 80 chars) and path
  - TodoWrite: full JSON
  - WebFetch, WebSearch and every other tool (MCP, Skill, ...): ignored, call and result
  - tool results: `ok <n> chars`, or bare `ERR` for errors
- The summarizer may also read files itself (`--allowedTools Read,Grep,Glob`).

## Warning before auto-compaction

Tool results are slimmed before they are summarized, so what an agent learned from a file it read or a command it ran is easily lost. Shortly before auto-compaction runs, the next tool result carries a short reminder for the model (never shown to you):

> Context is about 37k tokens from automatic compaction. Before it happens, write anything valuable that is not on disk yet (decisions and their reasons, findings from files you read or commands you ran, open questions, next steps) to one notes file (for example ./tmp/context-notes.md), then continue the current task. Do not stop to ask. Keep the note short; the compaction summary lists files you wrote.

The files it writes appear in the summary's `related_files`, so the notes are read again after compaction.

- Sent once per compaction cycle, from the main session only (not subagents), and armed again after compaction or when the context has fallen back by twice the margin.
- The distance is measured to the point where auto-compaction really runs: the engine's `autoCompactThreshold`, lowered by `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` when that is set (500k window, override 90: 467k reported, about 432k used), as a percent of the compaction window (`autoCompactWindow`).

### Options

Set them in `/config` (rows named after the plugin), or in `settings.json`:

```json
{
  "pluginConfigs": {
    "struct-compact": {
      "options": { "warnPercent": 10, "notesFile": "./docs/notes.md", "warnEnabled": true }
    }
  }
}
```

| Option | Default | Meaning |
| --- | --- | --- |
| `warnEnabled` | `true` | Turn the reminder off with `false` |
| `warnPercent` | `12` | Remind when this percent of the compaction window is left before compaction (1 to 50) |
| `autoCompactPctOverride` | empty | Your `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` value, for when the hook cannot read the environment variable. Empty reads the environment |
| `notesFile` | `./tmp/context-notes.md` | The file name the reminder suggests |

## Layout

```text
.claude-plugin/plugin.json
hooks/hooks.json     # { "modules": ["./register.ts"] }
hooks/register.ts    # session.compact handler, summary schema, rendering; tool.call reminder
hooks/warn.ts        # pure helpers of the reminder
tests/warn.test.ts
hooks/slim.ts        # rule-based slimming of tool calls and results
tsconfig.json        # extends .claude-plugin/types/tsconfig.json (editor typings only)
```

`.claude-plugin/types/` is generated by Claude Code for editor typings and is not committed.
